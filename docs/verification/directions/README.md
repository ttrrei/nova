# docs/verification/directions/

Audited evidence for the twelve fixed hourly direction hypotheses:
`results_index.json` (published run pointers), `instrument_results.csv`
(per-instrument screening), `trade_audit.json` + `trade_samples.csv`
(independent ledger audit and quote-fill samples), `replay.json`
(replay identity), `review_findings.json` (coordinator review),
`tests.xml`. Corresponding immutable runs live in `runs/directions/`.
