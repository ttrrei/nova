# background/moneta-next/migration/

Migration material from legacy Moneta into the v0.2 design:

- `DATA_CONTRACT.md` — the raw/canonical OHLCV data contract
- `MIGRATION_GUIDE.md`, `MIGRATION_SUMMARY.json`, `PROVENANCE.json`,
  `RESEARCH_KNOWLEDGE.json` — how the legacy project was carried over and what
  research decisions were kept
- `feature_catalog.json` — the feature vocabulary baseline
- `patches/` — diff artifacts describing legacy engine changes
- `reference/` — frozen copies of the legacy `config/`, `docs/`, `library/`,
  `pipeline/`, `research/`, `strategy/` and `tests/` used as design input

Read-only historical reference.
